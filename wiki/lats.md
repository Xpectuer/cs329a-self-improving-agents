# LATS（Language Agent Tree Search）

> Source(s): raw/ch-02-LATS 论文背景与问题定义, raw/ch-03-LATS 核心直觉与六个阶段, raw/ch-05-反思记忆与课堂讨论

LATS（Language Agent Tree Search，语言智能体树搜索）来自一篇 ICML 论文，标题为 *Language Agent Tree Search Unifies Reasoning Acting and Planning in Language Models*。它面向多步骤任务，将**推理**、**行动**与**规划**统一在同一个测试时搜索框架中。

## 动机与挑战

在多步骤任务（如规划一次假期旅行）中，模型不仅要进行推理（思考预算、计划内容等），还要通过行动获取更多信息（如浏览网页、生成搜索查询、阅读 Reddit 或旅行博客），并根据环境反馈进行搜索和规划（如考虑替代目的地、搜索当地新活动）。这类问题需要一系列**推理—行动—搜索**步骤才能最终解决。

论文希望解决的核心挑战是：从“让 LLM 生成计划并执行”转变为“真正鼓励模型生成多样化的计划/路径并进行探索”。模型需要创造多种解决方案，并根据行动结果进行多步优化，以最终逼近正确答案。

## 方法：将 MCTS 引入 LLM 推理路径

LATS 将强化学习与多步规划中的已有技术——尤其是**多步蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）**——引入 LLM 的推理过程。模型在探索环境时接收反馈，并将这些反馈带回以优化未来的计划和搜索过程。

LATS 的测试时搜索管线由六个阶段组成：

1. **选择（selection）**：基于 UCT 在当前搜索树中选择一个待扩展节点。选择过程需要在探索与利用之间取得平衡。
2. **扩展（expansion）**：从当前节点采样多个候选行动，在环境中执行这些行动，并把观测追加到上下文。行动可以**并行执行**，体现多行动采样（multi-action sampling）的特点。
3. **评估（evaluation）**：对行动所到达的新状态进行打分。分数由两部分合成：
   - **LM 分数**：使用 LLM-as-a-Judge，让模型直接为状态的前景给出 0 到 1 的评分；
   - **自洽性分数**：当采样了大量候选行动并按类型归类后，某类行动被采样越频繁，对应状态的分数越高。
4. **模拟（simulation）**：从得分最高的状态出发，采用贪心方式继续扩展，直到达到成功/失败等终点状态，或达到扩展预算。
5. **反向传播（backpropagation）**：将模拟结果回传，更新搜索路径上各状态的分数，以指导后续选择。
6. **反思（reflection）**：对成功或失败的轨迹进行反思，产生可用于后续搜索的经验与改进信号。

### 反思的作用

反思发生在反向传播完成之后。模型会针对被扩展的轨迹生成一段对自身的反思：无论这条轨迹失败还是成功，模型都会补充“是什么导致了失败或成功”的解释性思考。这种对成败轨迹的额外解释性文本被证明能显著提升整体搜索质量，并为后续搜索积累可复用的经验。

### 迷宫导航示例

假设 prompt 是“穿越迷宫到达出口”，初始观测为“身处昏暗房间，左右各有一扇门，目标是找到出口”。

- **选择**：根据 UCT 选中初始节点进行扩展。
- **扩展**：模型采样三个行动——开左门、开右门、检查房间线索；每个行动在环境中执行，观测被追加到上下文，例如“左门后是挂着画的黑暗走廊”。
- **评估**：假设进行了 50 次行动采样，“开左门”被高频选中，因此其自洽性分数更高；再结合 LLM 打分，合成状态 $s_A$ 的分数。
- **模拟**：$s_A$ 得分最高，于是从该状态贪心扩展，沿阶梯路径最终到达“出口门已清晰标记”的成功观测。
- **反向传播**：将成功结果回传，更新路径上各行动与状态的分数。
- **反思**：在模拟结束后总结成功经验，供后续搜索参考。

## 实验效果

LATS 在多个多步推理与决策数据集上取得了强结果，且无需微调，仅在测试时进行搜索即可获得接近人类专家的表现。

### HotPotQA

HotPotQA 是一个用于多步推理优化的数据集。每个问题至少需要从两个不同的 Wikipedia 页面检索信息，因此天然要求多步推理过程。实验表明：

- 随着采样轨迹数量增加，模型性能显著提升；
- 反思机制和带回的推理轨迹在最终效果上提供了额外提升；
- 整体上，LATS 提供了一种机制，将测试时更多的计算量有效转化为多步推理任务上更好的解决方案。

### WebShop

WebShop 是一个面向实际应用的数据集，任务同样被设计为多步过程。例如，用户需求可能是“找一个已经组装好的小型便携折叠桌，指定颜色、表面处理和价格范围”。LATS 在无需微调的情况下，仅靠测试时搜索就取得了很高的结果，甚至接近人类专家水平。

## 总结与讨论

LATS 提出的新方法将推理、行动和规划统一在一起，并把 MCTS 等成熟思想引入语言模型世界，在多个领域取得了强结果。由于其测试时方法和模块化设计，LATS 具备良好的可移植性，较容易构建和扩展。

课堂讨论中也指出了若干值得注意的方面：

- **成本问题**：每次反向传播和树的扩展都会引入大量测试时计算开销，而论文并未对成本收益进行系统分析。
- **可逆性假设**：LATS 隐含假设行动是可逆的。但在真实场景中，某些行动一旦执行便不可撤回，例如模型直接执行交易、支付服务等具有严重后果的操作。这类不可逆场景下，该方法的适用性受限。
- **探索-利用算法**：UCT 本质上来自多臂老虎机中的上置信界思想。论文并未系统比较其他探索-利用算法；其主要贡献在于搭建了一个平台，使后续研究可以接入更多优化方法。
- **重复行动的处理**：如果同一行动在给定父节点下重复出现，会增加该行动的计数，并通过 UCT 公式体现出来。LATS 构建的是搜索树而非全连接图，这是其路径归并与计数机制的基本假设。
