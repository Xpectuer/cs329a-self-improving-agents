# Planning

> Source(s): raw/ch-01-课程内容回顾, raw/ch-01-课程总览与主题引入, raw/ch-02-LATS 论文背景与问题定义, raw/ch-03-未来研究方向概览

## 概述

**Planning（规划）** 是智能体在行动前或行动过程中生成多步计划以完成复杂任务的能力。在 [[cs329a]] 课程中，它是第五讲 *Planning and Multi-Step Reasoning* 的核心主题之一，与该讲同时覆盖的 **多步推理（Multi-Step Reasoning）** 紧密相关。

从 LATS（Language Agent Tree Search）论文所针对的问题来看，这类多步任务不仅需要模型“推理（reasoning）”——例如判断任务预算是什么、整体计划如何制定；还需要“行动（acting）”——例如浏览网页、生成搜索查询、阅读 Reddit 或旅行博客以收集更多信息；并需要“搜索（search）”——根据环境反馈和在线收集到的信息，调整当前计划，考虑替代目的地、搜索当地可做的新活动等。也就是说，规划能力不是一次性生成一段计划，而是在整个多步任务中循环执行“推理、行动、搜索”的过程。

## 课程定位

在斯坦福 CS329A *Self-Improving AI Agents* 课程的第五讲中，规划与多步推理被作为重点议题进行讨论。该讲围绕这一主题选取了三篇论文进行深入讲解，旨在理解模型如何通过生成中间步骤、构建行动序列来解决需要长期推理或分阶段决策的复杂任务。

规划能力对于智能体的自主性至关重要：它使模型不仅能对单一查询给出回答，还能面向目标拆解任务、安排行动顺序，并在执行过程中根据新信息进行调整。这一能力也与其他关键主题相互关联，如 [[chain-of-thought]] 提示、[[inference-scaling]] 以及 [[verification]] 等。

从整门课程的脉络来看，规划与多步推理是课程从训练/测试时缩放转向真实世界工作流的关键转折点。课程前半段围绕 LLM 的训练时缩放（train-time scaling）与测试时缩放（test-time scaling），强调由验证器（verifier）、奖励信号、强化学习与搜索算法共同驱动的自我改进循环；随后讨论开放式的进化策略（如 alpha evolve），让模型在可定义的探索空间中自主探索。接着，课程进入“智能体端到端工作流”范式：模型通过工具使用与环境交互，从而驱动完整工作流。当任务需要在多个步骤中完成、并与外部世界持续交互时，模型就需要检索和记忆能力，也需要更强的规划和多步推理能力。课程最后一讲在回顾这些内容时再次强调：走向真实世界工作流，意味着模型必须具有更好的规划与多步推理能力。

与此同时，课程也以 **agent** 为视角重新定位了规划的意义。Agent 是 LLM 的推广：它有目标，会与环境交互、收集反馈，并利用反馈纠正自己的步骤；它是能够引导自身过程、使用工具并完成目标的系统。在当前范式中，LLM 自身往往还不足以独立驱动一个完整目标，因此常见做法是手写工作流来编排 LLM 与工具；但在 coding agents 等场景中，已经可以看到一些 agentic workflow 开始由模型自身驱动。这类工作流通常需要协调 LLM、验证器、LLM-as-judge、工具调用与搜索算法，也可能包含并行的 LLM 调用。无论具体编排方式如何，agentic workflow 的核心都指向目标导向的规划与多步推理：模型需要能够推理多个步骤、在方向错误时自我纠正，并通过自我改进循环持续提升能力。此外，有嘉宾还提到符号化技术（symbolic techniques）可以归入工具使用（tool use）的范畴，并有可能贡献于合成数据（synthetic data）这一趋势，这也与规划任务中结构化知识的使用密切相关。

## LATS：以搜索统一推理、行动与规划

LATS 论文的核心动机，是从“让 LLM 生成一个计划并执行该计划”进阶到“鼓励模型对不同的计划或路径进行多样化和探索”。模型需要能够产生多样化的候选方案，对它们进行行动，并通过多步优化来逼近最终正确解。

LATS 将强化学习与多步规划中的已有技术，特别是**多步蒙特卡洛树搜索（MCTS）**，引入到 LLM 的推理路径中。其关键思路包括：

- **动作采样与评分**：针对同一提示，模型可以产生不同的动作。例如在“计划一次夏威夷旅行”的任务中，模型可以选择询问去过夏威夷的朋友，也可以选择阅读相关 subreddit。框架为每个动作计算一个分数，并基于分数更新搜索空间和树的扩展方向。
- **树状搜索与并行执行**：高分的动作会被继续展开。例如“询问两个朋友”会进一步展开为分别询问朋友 A 和朋友 B，并根据回答质量继续评分和扩展。多个动作可以并行执行，形成一种多动作采样的搜索模式。
