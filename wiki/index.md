# Wiki Index

> Last updated: 2026-08-26

## Synthesis

- [[10-at-k]] -- 10@k：从 k 个候选解中选 10 个提交的受限评测指标，衡量生成与筛选/聚类能力；性能差异来自输入分布与选择瓶颈。
- [[agent-search]] -- 智能体搜索指在深度研究式多步任务的智能体动作/轨迹搜索空间中搜索以改进模型。
- [[agentic-evaluations]] -- 智能体评估评测多步、长时程、真实世界任务，衡量能力边界与经济价值，并关注下一代模型的自改进与智能效率。
- [[agentic-workflows]] -- 智能体工作流是通过工具使用、检索记忆、规划与多步推理端到端驱动真实任务执行的工作范式。
- [[aime]] -- AIME（2024/2025）是用于评测数学推理的新基准，因旧基准饱和污染而被引入，也是作业一使用的基准。
- [[alignment]] -- 对齐是微调的首要方面，通过引导模型遵循人类目标、偏好与价值观，弥补预训练模型缺乏指令遵循能力的问题。
- [[alphacode]] -- AlphaCode以输入/输出样例为契约端到端解题，经大规模采样与筛选后评测，10场竞赛排名前54%。
- [[chain-of-thought]] -- 思维链通过逐步推理示例引导模型，STaR增强推理，并延伸至强化学习与训练时计算，构成推理模型基础。
- [[chatgpt]] -- ChatGPT于2022年11月发布、5天达到100万用户，其成功来自指令微调与RLHF等对齐创新。
- [[codeforces-evaluation]] -- AlphaCode 在 Codeforces 真实竞赛上的在线评测：10 场约 5000 人比赛，平均排名 54.3，与 28% 参赛者相当
- [[competitive-programming-problem]] -- 竞赛编程问题是以题目描述和输入/输出样例为契约、要求模型端到端求解的编程任务。
- [[course-team]] -- 介绍CS329A课程团队：Akansha与Azalia的学术背景及合作经历
- [[cross-domain-self-improvement]] -- 跨领域自我改进：探讨自我改进从数学、编码等可验证窄域向跨领域泛化所需的研究方向与挑战。
- [[cs329a]] -- 斯坦福大学CS329A课程（自我改进型AI智能体）的欢迎与课程概要，涵盖教师介绍、课程网站及安排。
- [[dapo]] -- DAPO 是稳定长链推理强化学习的论文，强调实现细节的重要性，在 Qwen-32B 上于 AIME 取得约 50% 准确率。
- [[data-barriers]] -- 数据瓶颈：训练模型的提示与数据目前由人工静态选择，如何让自我改进循环自主挑选正确数据以突破数据壁垒是未来研究重点。
- [[deepscholar-bench]] -- DeepScholar-Bench是斯坦福大学提出的实时基准，通过让模型撰写相关工作章节来评估深度研究能力。
- [[deepseek-math]] -- DeepSeekMath 是 DeepSeek 团队关于数学推理增强的论文与模型，通过大规模数学语料预训练提升语言模型数学推理能力，为课程第三章第二篇论文。
- [[efficiency-for-intelligence]] -- 以“单位资源下的智能”衡量效率，探讨驱动智能效率提升的因素，是与自我改进同等重要的未来研究方向。
- [[emergent-abilities]] -- 解释大模型中涌现出的、小模型不具备的能力，如推理、少样本学习和思维链。
- [[few-shot-learning]] -- 通过在提示中附加少量示例，模型无需微调即可完成新任务；该能力随模型规模增大而涌现。
- [[fine-tuning]] -- 微调是预训练后使用高质量数据（含模型自身生成轨迹）对齐人类偏好的关键流程，计算强度远低于预训练。
- [[fundamental-capability-scaling]] -- 自我改进与RL技术仅提升pass@k、格式与连贯性，不能提升模型根本能力；根本能力跃迁需突破或规模扩展。
- [[gdpval]] -- GDPVal是OpenAI发布的基准，通过模型完成任务相对于专家的胜率衡量其真实世界经济价值能力。
- [[generation-verification-gap]] -- 模型生成能力强于验证能力；在有限提交预算下，筛选与聚类成为瓶颈，10@k 与 pass@k 差距明显，体现生成-验证差距。
- [[gold-loss]] -- GOLD 是 AlphaCode 微调阶段按 token 似然加权 next-token 损失的正则化技术，用于提升精度并赋予高概率给有意义模式。
- [[gsm8k]] -- GSM8K是由OpenAI在2021年提出的8,500道小学数学应用题基准，强调问题质量、多样性与多步推理，至今用于小模型评测。
- [[hotpotqa]] -- 多步推理评测数据集，每题需跨两个维基页面检索；LATS 经采样与反思显著提升其性能。
- [[humaneval]] -- HumanEval 是代码生成领域经典评测基准，用于验证通过大量采样搜索筛选答案的搜索模式效果
- [[inference-scaling]] -- 推理时计算扩展：不改变参数、不做微调，在推理阶段投入更多计算提升模型，并驱动工程范式转向推理侧投入。
- [[instruction-tuning]] -- 指令微调是让预训练模型遵循指令与人类偏好的关键微调阶段，支撑了ChatGPT等对话模型。
- [[large-language-models]] -- CS329A 对大语言模型及扩展趋势的概述，涵盖课程团队、安排与季度内容回顾。
- [[large-language-monkeys]] -- 大量并行采样与验证器筛选提升推理能力；求解率随采样预算对数线性增长，体现推理期算力投入范式转变。
- [[lats]] -- LATS将MCTS引入LLM推理，统一推理、行动与规划，通过轨迹反思与环境反馈实现测试时搜索。
- [[llm-as-a-judge]] -- LLM-as-a-Judge 是一种用提示词让大语言模型打分的机制，用于 LATS 评估阶段及更广泛的智能体工作流中的验证与奖励信号。
- [[math-shepherd]] -- 用自动步骤标签训练 PRM 并以 PRM 为奖励模型强化生成器，在数学推理上无需人工标注超越基线。
- [[mathematical-reasoning]] -- 数学推理是语言模型的多步逻辑推理能力，可经预训练、验证器与强化学习增强，常用于GSM8K与MATH。
- [[meta-verification]] -- 元验证：验证进入推理链的内容，构建鲁棒验证技术是自改进循环的重要未来方向。
- [[metr]] -- METR 是以人类专业人员完成时间为锚点、衡量模型可完成任务时间跨度的基准，结合 50%/80% 成功率评估可靠性。
- [[model-size-growth]] -- 大语言模型参数量从BERT到GPT-4呈指数级增长，驱动基准性能、零样本与少样本学习及涌现能力持续提升。
- [[multi-step-reasoning]] -- 多步推理指模型需经多个逻辑步骤得出答案的能力，是规划与复杂问题求解的基础，也是CS329A第五讲核心主题。
- [[multimodal-agents]] -- 多模态智能体方向：处理视觉等输入并执行任务，是课程中客座讲座覆盖的重要前沿主题。
- [[open-endedness]] -- 开放式演化不依赖奖励驱动，而是在可定义的探索空间中自由探索，代表如 AlphaEvolve 等演化策略。
- [[planning]] -- 智能体规划指模型通过推理、行动与搜索生成多步计划以完成复杂任务，是CS329A第五讲核心主题。
- [[pre-training]] -- 语言模型训练的第一步，通过预测下一个token学习海量文本的统计知识，为后续微调和对齐奠定基础。
- [[prm800k]] -- PRM800K是OpenAI用于训练过程奖励模型的人类标注步骤级数据集，包含80万个步骤标注，Math-Shepherd在MATH上超越它。
- [[process-reward-model]] -- 过程奖励模型（PRM）对推理每一步打分，属过程监督，比结果监督更细粒度，但需标注数据，Math-Shepherd尝试自动标注。
- [[prompt]] -- prompt 是向模型描述任务的输入文本，触发零样本与少样本学习的关键机制。
- [[reasoning-training-techniques]] -- 对比STaR、DeepSeekMath+GRPO、DAPO三种推理训练技术的适用场景与RL/SFT取舍。
- [[retrieval-and-memory]] -- 真实世界多步任务需要检索与记忆能力，并进而要求规划、多步推理和自我改进。
- [[reward-hacking]] -- 奖励模型在 agent 过强或信号不足时失效，导致 RL 优化难以 hill-climb 甚至饱和，这是 RL 训练的核心困难。
- [[rlef]] -- RLEF通过执行反馈引导代码LLM，是训练时扩展课程中利用执行信号进行强化学习的论文。
- [[rlhf]] -- 基于人类反馈的强化学习（RLHF）通过对齐人类偏好微调模型，是ChatGPT成功的关键创新之一，但仍未完全解决。
- [[robotics-agents]] -- 机器人与智能体方向：将智能体能力延伸到物理世界的控制与决策，课程客座讲座覆盖内容。
- [[scaling-laws]] -- 大语言模型的规模扩展定律：计算量、数据集和参数规模增大时测试损失下降，模型性能提升。
- [[self-consistency]] -- 自洽性既指思维链多数投票，也指 LATS 中按行动采样频率给状态打分并与 LM 分数相加。
- [[self-improving-ai-agents]] -- CS329A核心概念，指通过验证器、奖励、强化学习与搜索闭环自主提升能力的AI智能体，并展望开放探索与未来研究方向。
- [[solution-clustering]] -- 对语义等价的候选解聚类，从百万级采样中精选多样化少量提交，以支撑最终评估并提升10@k
- [[sprint]] -- SPRINT 是 NeurIPS 2025 的推理加速框架，后训练阶段将推理模型转化为规划器与并行执行器，利用推理步骤独立性加速推理。
- [[star]] -- STaR（Self-Taught Reasoner）是斯坦福大学提出的通过自生成推理过程迭代微调提升模型推理能力的方法。
- [[synthetic-data]] -- 合成数据是当前显著趋势，由符号技术与工具使用共同推动生成，是突破数据壁垒、训练下一代模型的重要方向。
- [[test-loss]] -- 测试损失是语言模型性能的核心指标，随计算量、数据量、参数量的增加而降低。
- [[tool-calling]] -- 符号技术属于工具使用范畴，可促进合成数据生成，是工具调用与智能体工作流的重要方向。
- [[train-time-scaling]] -- 训练时扩展指在训练阶段通过强化学习等闭环反馈提升模型能力，与推理时扩展互补的范式。
- [[verifiable-domains]] -- 某些领域更易自动化验证：数学、编程、语言转换等，通过形式化证明、单元测试、输出等价性检查验证生成结果，并支撑训练时扩展。
- [[verification]] -- 验证：借助验证器/奖励模型自动挑选或引导正确答案以弥合生成-验证差距，衔接测试时与训练时扩展。
- [[webshop]] -- WebShop 是面向在线购物场景的多步决策数据集，LATS 无需微调即可接近人类专家表现。
- [[zero-shot-learning]] -- 模型仅凭任务描述（prompt）即可直接预测答案，无需针对特定任务训练或提供示例的能力，是大型语言模型的涌现能力。
