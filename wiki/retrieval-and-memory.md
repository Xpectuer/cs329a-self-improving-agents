# Retrieval and Memory

> Source(s): raw/ch-01-课程内容回顾, raw/ch-03-未来研究方向概览

在课程回顾中，Retrieval and Memory（检索与记忆）被定位为从工具使用走向真实世界多步任务工作流的关键能力，属于整季课程脉络中的一个重要环节。在未来的研究方向概览中，这一能力又被放入更广义的 self-improving agents（自我改进型智能体）框架中，成为驱动智能体持续提升的基础要素之一。

## 课程背景

本季度课程首先介绍了 LLM 的概貌，并强调了过去一年中，test-time scaling（测试时缩放）和 train-time scaling（训练时缩放）如何通过自我改进技术形成基本循环。该循环由 verifier（验证器）驱动，通过反馈与奖励，结合强化学习和搜索算法，帮助模型在数学、编程等领域持续提升。

随后，课程转向进化策略（evolutionary strategies）。在 open-endedness（开放世界探索）的框架下，模型不再仅仅由奖励驱动自我改进，而是可以在定义好的探索空间中自由探索，相关技术包括 alpha evolve 及类似方法。

课程也反复强调，这门课关注的不只是 LLM 本身，而是 agent（智能体）层面。agent 是 LLM 的一种推广：它有目标，会与环境交互、收集反馈，并利用反馈修正自己的步骤。它是能引导自身过程、使用工具并最终完成目标的系统。在当前的范式下，LLM 本身往往不足以独立完成完整目标，因此常需要以 workflow（工作流）方式编排 LLM 与工具；但在 coding agent 等场景中，部分 agentic workflow 已开始由模型自主驱动。

## 端到端 Agent 工作流

接着，课程进入一个范式转变：利用工具使用（tool-use）构建 agent 的端到端工作流。模型通过与环境和工具交互，端到端地驱动整个工作流。当任务需要在多个步骤中完成时，模型必须能够查询知识库——这便提出了检索（retrieval）和记忆（memory）的需求。

在具体实现上，这类 agentic workflow 通常意味着编排 LLM、编排 verifier（因为需要某种形式的奖励），可能会把 LLM 当作 judge 来充当 verifier，也可能会接入 tool calls 和 search algorithms。例如，多个并行的 LLM 调用可以共同执行某种搜索。由于整个 workflow 面向目标推进，它需要具备规划、多步推理、在方向错误时自我纠正，并持续提升自身能力——这正是 self-improvement 的来源。

## 检索与记忆的重要性

真实世界的工作流通常需要多步骤完成，因此模型需要具备查询外部知识库的能力。这意味着：

- **检索**：在任务过程中主动定位并获取相关知识；
- **记忆**：在长上下文中保持并利用已获取的信息。

课程指出，走向真实世界工作流时，模型还需要更好的规划（planning）和多步推理（multi-step reasoning）能力，并深入探讨了如何评估下一代模型，以及哪些能力会驱动这些评估。

## 嘉宾讲座与前沿方向

课程后半部分邀请了多位嘉宾，主题涵盖后训练（post-training）、多模态 agent、机器人、推理等。其中一位嘉宾还谈到符号技术（symbolic techniques）——它可归入工具使用范畴，并能贡献于合成数据（synthetic data）这一正在出现的趋势。Azalea 在课堂讨论中也确认了这一判断：符号技术属于 tool use 的伞形框架之下，且能进一步强化合成数据这一方向。

## 未来研究方向

在课程末尾的“未来研究方向”概览中，检索与记忆被置于更宏观的 self-improvement 研究议程中。基于课程所学，以下方向被认为是亟需突破的重点：

- **跨领域泛化**：test-time scaling 和 train-time scaling 目前仍较多局限于数学、编程等窄领域。如何将自我改进循环推广到更广泛的领域，并让 reasoning chain（推理链）足够多样化，从而持续驱动改进，是重要的开放问题。
- **可靠验证**：构建自我改进循环时，验证环节始终关键。如何设计 robust verification（稳健验证）乃至 meta verification（元验证）技术，去核查进入推理链的内容，是很有价值的研究方向。
- **突破数据壁垒**：当前训练模型所用的 prompt 往往由人类静态挑选。如何让自我改进循环自主选择正确的数据、打破数据瓶颈，是下一步的核心挑战。
- **智能效率**：除了自我改进本身，研究者还应关注“单位资源下的智能效率”（intelligence per what aspects），即如何更高效地获得和利用智能。

这些方向将共同影响下一代 agentic systems 的构建方式，也让检索、记忆、规划、验证与数据选择在一个更完整的自我改进循环中彼此耦合。

## 总结

检索与记忆是多步 agent 走向实际应用的基础能力，与工具调用、规划和多步推理紧密耦合，也是评估下一代模型能力的重要维度。在更广义的 self-improving agents 框架下，它并非孤立的能力，而是与验证、搜索、数据选择等机制共同支撑智能系统持续提升。
