# 智能体工作流（Agentic Workflows）

> Source(s): raw/ch-02-Self-Improving Agents 的概念与工作流；raw/ch-03-未来研究方向概览

智能体工作流（agentic workflows）是一种以大型语言模型为核心，通过工具使用、检索记忆、规划与多步推理端到端驱动真实世界任务执行的工作范式。它不再是一次性的“输入-输出”提示响应，而是让模型在多轮循环中调用工具、查询记忆、制定计划并动态调整行动，从而完成复杂任务。在 ch-02“Self-Improving Agents 的概念与工作流”中，该概念作为“工作流”部分的主题被提出，旨在整合散落在多个页面中的相关能力。

在 ch-03 的课程总结中，智能体被进一步定义为 LLM 的泛化：它拥有明确目标，会与所处环境交互、收集反馈并用这些反馈纠正自身步骤，从而自主引导过程、使用工具并达成目标。智能体工作流则是这一泛化过程的具体实现形态——当前常常由人类手工编排 LLM、验证器、LLM 裁判、工具调用与搜索算法，但在编码类智能体等场景中，模型已开始尝试自主驱动这些工作流。

## 核心组件

智能体工作流通常整合以下能力：

- **工具使用**：通过调用外部 API、代码解释器、搜索引擎或专用工具来获取信息、执行操作。相关概念参见 [[tool-calling]]。
- **检索与记忆**：从外部知识库或长期记忆中检索相关内容，并维护会话状态与历史信息。相关概念参见 [[retrieval-and-memory]]。
- **规划**：将复杂任务分解为子目标或步骤，并制定执行顺序。相关概念参见 [[planning]]。
- **多步推理**：在多个步骤中维持连贯推理链条，利用中间结果逐步逼近最终答案。相关概念参见 [[multi-step-reasoning]] 与 [[chain-of-thought]]。
- **验证器与奖励信号**：工作流常需要某种形式的奖励信号，因此会编排验证器（verifiers）来检查中间或最终结果，甚至用 LLM 作为裁判（LLM-as-judge）来执行验证。参见 [[verification]] 与 [[reward-hacking]]。
- **搜索算法与并行调用**：在决策空间中可引入搜索算法，并让多个 LLM 实例并行调用以探索不同路径；这类机制也属于推理时扩展的范畴（如 [[lats]]、[[dapo]]）。

这些组件并不是孤立存在的，而是端到端地协同工作。例如，一个智能体可能先检索资料，然后规划步骤，再调用工具验证结果，最后基于多步推理给出答案；在此过程中还可能需要验证器或 LLM 裁判来提供反馈，并通过搜索或并行探索进一步优化决策。

## 与相关概念的关系

- **自我改进智能体**：智能体工作流为自我改进提供了执行平台，使智能体能够通过在任务执行中积累经验来优化自身策略。参见 [[self-improving-ai-agents]]。
- **推理时扩展**：多步规划与工具调用属于推理时计算扩展的范畴，允许模型在生成答案时投入更多计算。参见 [[inference-scaling]]、[[inference-scaling]] 与 [[train-time-scaling]]。
- **智能体评估**：由于工作流涉及与环境的多轮交互，其评估方式也从单轮基准扩展到交互式环境。参见 [[agentic-evaluations]]、[[webshop]] 与 [[deepscholar-bench]]。
- **验证与对齐**：动态执行真实任务可能引入新风险，因此需要关注 [[verification]]、[[alignment]] 与 [[reward-hacking]]。

## 应用场景

- 在开放世界任务中，智能体通过网页交互、工具调用来完成购物、信息检索等操作（如 [[webshop]]）。
- 在数学推理中，结合工具（如代码计算）与多步推理来增强准确性（参见 [[mathematical-reasoning]]、[[deepseek-math]]）。
- 在多模态环境中，智能体还可与物理世界或其他软件系统交互，参见 [[multimodal-agents]]、[[robotics-agents]]。
- 在编码任务中，已经出现由智能体自主驱动端到端工作流的趋势：模型自行编排代码编写、测试执行、错误修复等步骤。

## 挑战与展望

智能体工作流的主要难点包括长程任务的稳定性、错误累积、工具结果的可信度，以及如何从交互反馈中持续学习。当前其构建方式仍以人类手工编排为主，即开发者需要提前设计 LLM、验证器、LLM 裁判、工具调用和搜索算法的组合流程；而在编码等领域，模型已开始逐步具备自行驱动这类工作流的能力，因此如何将这种自主性扩展到更广泛的任务是一个关键方向。

ch-03 进一步归纳了以下未来研究重点：

- **跨领域泛化的自我改进**：测试时扩展与训练时扩展在数学、编码等狭窄领域已取得进展，但如何将自我改进循环推广到更广泛领域，并让推理链保持足够多样性以持续驱动改进，仍是开放问题。
- **稳健验证与元验证**：在自我改进循环中，验证环节至关重要。如何构建稳健的验证技术，甚至对进入推理链的信息进行“元验证”（meta-verification），是值得深入的方向。
- **突破数据屏障**：当前训练数据与提示词的选择常常是静态的、依赖人工筛选。让自我改进循环能够自主选择合适的数据来驱动自身迭代，是打破数据瓶颈的重要方向。
- **智能的效率度量**：需要更清晰地回答“智能的效率”究竟以什么为分母——是算力、数据、参数还是交互次数，这将成为下一代系统设计的重要导向。
- **符号技术与合成数据**：在工具使用的大框架下，符号化技术可以增强逻辑与可解释性；同时，合成数据也是提升工作流能力的重要趋势。

未来方向还包括将 [[self-improving-ai-agents]] 的自我改进机制更深度地融入工作流，以及优化推理时规划策略（如 [[lats]]、[[dapo]]）。
