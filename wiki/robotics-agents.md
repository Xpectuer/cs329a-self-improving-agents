# robotics-agents

> Source(s): raw/ch-01-课程内容回顾

robotics-agents 是课程回顾中提到的客座讲座所涉及的机器人方向，探讨如何将智能体能力延伸到物理世界的机器人控制与决策。它建立在本季度前半段关于 LLM 自我改进、工具使用、规划与多步推理等讨论之上，是智能体从数字环境走向真实世界工作流的重要延伸。

## 课程主线回顾

本季度课程最初围绕 LLM 展开，重点包括：

- **Test-time scaling 与 train-time scaling**：过去一年中，利用自我改进技术驱动模型能力提升成为核心趋势。
- **Verifier 与奖励反馈**：通过 verifier 运行并获得奖励，形成自我改进的基本循环。
- **强化学习与搜索算法**：帮助模型在数学、代码等任务上持续提升。

随后课程进入**进化策略与开放探索**：

- 不再仅由奖励驱动自我改进循环，而是允许模型在可定义的探索空间中自由探索。
- 讨论了 **alpha evolve** 等类似技术。

接着转向**基于工具使用的端到端智能体工作流**：

- 模型与环境、工具交互，端到端驱动工作流完成。
- 面对多步骤任务，需要访问知识库，因此引入 **retrieval 与 memory**。
- 真实世界工作流对模型的 **planning 与多步推理** 能力提出更高要求。
- 讨论了下一代模型评估及其所需能力。

在课程后半段，多位客座讲师覆盖了 **post-training、multimodal agents、robotics、reasoning** 等方向。其中一位还讨论了**符号技术**，它属于工具使用范畴，并为合成数据这一趋势做出贡献。

## robotics-agents 的定位

robotics-agents 是客座讲座中提到的机器人方向，核心关注：

- 将前序讨论的智能体能力延伸至物理世界。
- 面向真实机器人场景的**控制与决策**。
- 与工具使用、多步推理、检索与记忆等能力天然衔接，是智能体从纯数字任务走向物理世界工作流的代表方向。
