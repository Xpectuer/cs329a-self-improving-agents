# 合成数据（Synthetic Data）

> Source(s): raw/ch-01-课程内容回顾, raw/ch-03-未来研究方向概览

合成数据（synthetic data）是当前另一个显著趋势。在课程回顾与"未来研究方向"两次讲座中，Azalea 均指出，符号技术（symbolic techniques）属于工具使用的范畴，并且这类技术可以为合成数据的生成提供支撑。正如她在未来研究方向讲座中所言，嘉宾提到的符号技术归属于工具使用的总框架之下，可以为合成数据这一趋势添砖加瓦。

在课程的整体语境中，合成数据与多个前沿方向密切相关：课程覆盖了 LLM 的测试时扩展与训练时扩展、基于验证器和奖励反馈的自我改进循环、强化学习与搜索算法在数学和编码任务上的应用、进化策略与开放-endedness 探索、端到端 agent 工作流、工具使用、知识库检索与记忆、规划与多步推理、下一代模型评估，以及后训练、多模态 agent、机器人等嘉宾讲座主题。

合成数据作为被提及的趋势之一，可以视为这些技术共同推动的能力跃迁中的关键要素：通过符号技术和工具使用，模型能够生成高质量、可验证的训练数据，从而进一步驱动自我改进和 agent 工作流的迭代。

在未来研究方向讲座的课程脉络回顾中，主讲人梳理了本季度的完整路径：自我改进的基本循环由验证器及奖励反馈驱动，并借助强化学习与搜索算法帮助模型在数学和编码等任务上持续攀升；随后是进化策略与开放-endedness 探索，让模型在可定义的探索空间中自由探索（如 AlphaEvolve 等）；再进入端到端 agent 工作流，模型通过工具使用与环境交互，逐步完成多步任务，并因此需要知识库检索与记忆、规划与多步推理能力。

在这条脉络中，合成数据的重要性尤为突出。其一，Azalea 明确将其列为与符号技术、工具使用并列的"正在出现的趋势"（another trend we are seeing），且符号技术为合成数据生成
