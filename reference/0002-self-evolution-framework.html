课程实例（CS329A 第 2 讲）：生成 → 验证 → 学习 → 搜索——模型生成候选解 → 验证器打分 → 反馈转为奖励信号 → 强化学习更新策略 → 推理时搜索探索更优候选。wiki/self-improving-ai-agents

2.1 测试内 vs 测试间：怎么分

判据只有一个：学习相对于任务执行的时序——任务进行中发生的适应是「测试内」，任务与任务之间发生的持久更新是「测试间」。（综述 §4：intra = occurs during task execution；inter = occurs between task completions）

维度测试内 intra测试间 inter
时序任务执行中，实时（在线）任务完成后，回顾式
数据当前任务实时产生的反馈积累的轨迹 / 奖励 / 经验
优化目标当前这道题的表现未来一系列任务的表现
典型机制ICL：自我反思 + 任务内记忆缓冲SFT / RL；也可 ICL（上次经验作下文）
效果持久性任务结束即失效（除非写回持久层）跨任务保留（权重 / 技能库 / 记忆库）
CS329A 对应测试时扩展方向（当其含经验反馈时）训练时扩展（train-time scaling）
代表系统Self-Refine / Reflexion（反思重试）、LATS 任务内搜索、LADDER（测试内 RL）STaR / Quiet-STaR、SELF、GRPO、DAPO、WebRL

两个易错点：① 机制 ≠ 时序——ICL 也有「测试间」用法（把上次经验归纳为工作流并注入下文），RL 也有「测试内」用法（LADDER 对单难题做目标 RL），判别只看时序。② 测试时计算扩展 ≠ 测试内自进化——纯采样+筛选（best-of-n、AlphaCode 提交筛选）不改任何行为，是"算力换答案"；有反思/反馈驱动的行为修改才算演化。

来源：Gao et al. arXiv:2507.21046 §1、§4。

3. 三标准（操作性定义）

定义：自进化 agent 是基于自身轨迹或反馈信号，修改其内部参数、上下文状态、工具集或架构拓扑，且明确以提升未来性能为目标的 agent（Gao et al. §2.1）。

这一定义蕴含三条纳入标准（要算「真自进化」，三条都满足）：

#标准含义反例
(i)经验驱动更新由自身轨迹、自生成数据或环境反馈驱动，针对能力边界，而非通用数据合成仅按人工静态数据集微调
(ii)持久效果产生持久的、改变策略的作用，而非一次性执行的临时行为仅对话内临时改 prompt
(iii)自主探索具备自主探索或自发学习的机制（自我反思、主动结构化修改）完全由外部排程触发的原型

连续光谱：proto-evolution（迭代 bootstrap、反馈驱动提示）→ strong self-evolution（完全自主诊断与重配置）；综述不设硬性边界。

4. 形式化（一行版）

$$\Pi_{j+1} = f(\Pi_j, \tau_j, r_j), \quad \max_f \sum_j U(\Pi_j, T_j)$$

Π 智能体系统，τ 轨迹，r 反馈，f 自进化策略，U 效用；改来改去都是为了下一轮任务表现更好（Gao et al. §2.1）。
