训练时扩展速查卡

第 4 课配套参考 · 长链推理 RL 的三件事：闭环、监控、稳定化

核心一句话：把「测试时扩展」那一步里被验证器挑中的输出，拿来微调回模型——训练时扩展。

1. 核心闭环

模型输出 → 测试时扩展（采样/搜索）→ 验证器过滤（挑正确解）
    ↑                                              ↓
    └──── 再生成（更强）← 用挑选的输出微调模型 ←──────┘

讲者原话：先应用测试时扩展，再对筛选出的模型自身输出进行过滤并微调回模型。忘了其他内容，记住这个循环，就掌握了训练时扩展。

2. 三种训练范式

范式做法
预训练互联网大规模数据，建立基础能力（第 1 讲）
微调RLHF / RLAIF，偏好数据对齐，得到聊天模型
训练时扩展在测试时扩展之上闭环：生成→过滤→训练→再生成

3. 三套训练方法怎么选

方法适用特点
STaR只有 ~100 个推理示例、无 RL 基础设施自生成 rationales → 验证筛正确 → 迭代微调；简单任务（GSM8K）有效，提升有限
GRPO（DeepSeekMath）基础模型 + 指令数据就绪，标准数学推理组相对优势替代 critic；内存友好；AIME 51.7%（7B）

叠加项得分

+ 非对称裁剪38

4.1 序列级 vs Token 级损失（为什么长答案与短答案等权）

标准 GRPO 实现（verl seq-mean-token-mean / OpenRLHF token_level_loss=False）按序列归一化——每个序列权重相同，与长度无关：

$$L_{\text{seq}} = \frac{1}{B}\sum_{i=1}^{B}\left(\frac{1}{T_i}\sum_{t=1}^{T_i}\ell_{i,t}\right)$$

DAPO 改为按token归一化（verl token-mean / OpenRLHF token_level_loss=True）——每个激活 token 同权，序列影响力 ∝ 它的 token 数：

$$L_{\text{dapo}} = \frac{\sum_{i=1}^{B}\sum_{t=1}^{T_i}\ell_{i,t}}{\sum_{i=1}^{B}T_i}$$

📔 NOTE · 逐符号拆解 DAPO 损失

$$L_{\text{dapo}} = \frac{\sum_{i=1}^{B}\sum_{t=1}^{T_i}\ell_{i,t}}{\sum_{i=1}^{B}T_i}$$

符号含义
$L_{\text{dapo}}$整个 batch 的聚合损失——每个激活 token 平均后的损失（标量）
$B$batch 内序列总数（每个问题采样多条回答，拼成一个组）
$i$序列下标，$1 \le i \le B$
$t$token 下标，$1 \le t \le T_i$
$T_i$第 $i$ 条序列的有效响应 token 数（response mask 激活部分；不含 prompt 前缀）
$\ell_{i,t}$第 $i$ 条序列第 $t$ 个 token 的裁剪策略梯度项（PPO 式）：
$\ell_{i,t}$ 展开$$-\min\!\left(r_{i,t}A_i,\ \operatorname{clip}(r_{i,t},1-\varepsilon,1+\varepsilon)\,A_i\right)$$
取 $\min$ 是为了在旧/新策略差距过大时「截断」更新幅度，防止训练爆炸
$r_{i,t}$重要性比率：$\pi_\theta(o_{i,t}\mid \cdot)\big/\pi_{\theta_{\mathrm{old}}}(o_{i,t}\mid \cdot)$ —— 新旧策略在 token $t$ 上的概率比
$\varepsilon$裁剪半径（通常 0.2）：允许策略单步更新的最大偏离比例
$A_i$第 $i$ 条序列的组相对优势（GRPO：$(r_i-\bar r)/\sigma_r$，组内归一化）——序列级标量，广播到该序列所有 token；DAPO 不提供逐 token 信用分配
分子 $\sum_{i=1}^{B}\sum_{t=1}^{T_i}$batch 内所有序列、所有 token 的损失总和
分母 $\sum_{i=1}^{B}T_i$总激活 token 数——用 token 总数而非序列数 $B$ 归一化，正是「每个 token 等权」的关键：序列影响力 ∝ 它的 token 数（长序列主导聚合）

数字例子：10 token 好答案（均值损失 $1.0$）+ 100 token 胡扯长答案（均值损失 $0.2$）→ 序列级 $= (1.0+0.2)/2 \approx 0.6$（等权）；token 级 $= (10\times 1.0 + 100\times 0.2)/110 \approx 0.273$（长序列主导聚合）。

⚠️ 两条易混轴：① loss 聚合层级——DAPO 改的是这个（loss reduction）；② 逐 token 信用分配——DAPO 未提供（奖励仍是序列级标量 A_i，广播到该序列全部 token；那是 PRM/过程奖励的事，见速查卡 0003）。

实践后果：序列级下模型发现「堆废话不改变序列权重、还能摊薄每 token 梯度」→ 长度膨胀信号被稀释，助长 reward hacking；token 级让每个废话 token 实打实承担梯度 → 天然抑制长度失控。单开 token 级不够，需与非对称裁剪、软超长惩罚、动态采样配合（见上表）。

5. RL 训练必须监控的三个指标

  1. 响应长度：持续膨胀但质量不升 → 奖励被 hack / 靠冗长偷分
  2. 熵：太低 = 坍缩；太高 = 不稳定失控
  3. 全对样本占比：决定需要多少采样；训练多步无改善 → 奖励可能已饱和

损失函数本身不是充分的代理指标——必须同时看这三个。

6. 能力边界（诚实面）

  • ✅ 提升 pass@k · 改善答案格式 · 增强多步推理连贯性
  • ❌ 无法提升根本能力 · 无法解决全新问题 · 无法大幅跨领域泛化
