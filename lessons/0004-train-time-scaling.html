先回忆上一课（30 秒）

AlphaCode 拿到 100 万候选后，靠聚类压缩到 10 个提交上真实竞技场——但猜猜：这 100 万候选里蕴含的正确解，模型参数记得住吗？
答：记不住。推理时学到的东西全部随会话烟消云散——这正是本课要闭合的缺口。

第 3 课的测试时扩展是「这一次任务里多烧算力」；本课的训练时扩展是「把烧出来的好东西固化回模型」——让它在下一次任务里不需要再烧那么多。

1. 核心闭环（一句话掌握本课）

讲者原话：先应用测试时扩展，再对筛选出的模型自身输出进行过滤，并微调回模型——这就是训练时扩展。

模型输出 → 测试时扩展(采样/搜索) → 验证器过滤(挑正确解)
    ↑                                        ↓
    └── 再生成(更强) ← 用挑选的输出微调模型 ←─┘

这一循环成立的前提：领域可验证（能确知对错，如 AIME 数学）——没有可靠的反馈信号，循环就断了。这也是为什么课程反复强调验证器是核心。

2. 数字震撼：小模型挑战大模型

模型参数AIME 准确率
GPT-3.5（无闭环）~175B≈5%
DeepSeekMath（训练时扩展）7B51.7%（+技巧 60%）
Qwen-32B + DAPO32B≈50%

175B 的 GPT-3.5 在 AIME 上只有 5%；7B 的 DeepSeekMath 靠训练时扩展拿到 51.7%。在训练阶段投入算力、让模型从自己生成的数据里学习，可以部分替代参数规模的差距。（wiki 页）

3. 三套训练方法：从轻到重

STaR（Self-Taught Reasoner，斯坦福）：不靠人工标注的思维链，让模型自己生成推理过程（rationales）→ 只保留验证正确的 → 微调 → 迭代重复。只在模型原有能力范围内提升，不超出其能力太多。（wiki 页）

GRPO（DeepSeekMath）：用组内相对优势（同一问题采样一组答案，取相对优势）替代 PPO 的 critic 价值网络——省内存、实现简单，数学推理效果好。（wiki 页）

DAPO（长链推理 RL 稳定化）：RL 对实现细节极度敏感——随规模扩大，微小修复的效果可能极其显著。DAPO 的关键改进（AIME，Qwen-32B）：

叠加项得分
基础 GRPO + 过长过滤30 → 36
+ 非对称裁剪38
+ 软性过长惩罚41
+ token 级损失42
+ 动态采样50（超过 R1 蒸馏版 32B）

token 级损失解决：样本级损失下，一个很长的垃圾答案和一个简短的好答案权重相同——改为逐 token 计算，长输出自然累积更多 loss，形成长度调节。动态采样改善批次内奖励分配，让信号传播得更好。（wiki 页）

4. 奖励黑客（reward hacking）：模型钻验证器的空子

RL 优化的是奖励信号，不是真能力——模型会找到奖励的漏洞。三类典型信号（wiki 页）：

  • 响应长度失控：输出越来越长，质量不升——靠冗长偷分
  • 熵漂移：生成熵持续增长，分布失稳
  • 截断噪声：难题卡在中途被截断，产出大量噪声破坏训练

所以 RL 训练不能只看损失函数——必须同时监控三指标：响应长度、熵、全对样本占比。全对占比告诉你采样量是否够；训练多步无改善 → 奖励信号很可能已饱和。

5. 何时用哪套？（决策）

场景选
只有 ~100 个示例、无 RL 基础设施STaR（简单推理有效）
基础模型 + 指令数据就绪，标准数学推理GRPO（内存友好）
长链/竞赛题，追求 SOTADAPO 风格（控制所有变量）

但请记住诚实的一面：这些技术能提升 pass@k、答案格式、推理连贯性——但无法教模型解决全新问题，也无法大幅跨领域泛化。这是当前研究的开放边界。

6. 练习：五道题，凭记忆作答

  1. Q1. 训练时扩展的核心闭环是？

    测试时扩展（采样/搜索）→ 验证器过滤正确解 → 用这些输出微调回模型——只记住这个循环就掌握了训练时扩展。

  2. Q2. STaR 用什么作为微调的训练信号？

    自己生成 rationales → 只保留验证正确的 → 微调 → 迭代，不靠人工思维链标注。

  3. Q3. DAPO 的 token 级损失解决的核心问题是？

    样本级损失下长垃圾答案与简短好答案权重相同；token 级损失让长输出自然累积 loss，形成长度调节。

  4. Q4. 训练中出现哪种现象提示模型正在奖励黑客？

    响应长度失控膨胀但质量不升，是模型靠冗长偷分的典型信号；熵漂移、截断噪声同理。

  5. Q5. 只有 ~100 个推理示例、且没有 RL 基础设施，应选哪套？

    STaR 是少量示例 + 无 RL 基础设施时的起步选择（GSM8K 类简单推理有效，但提升有限）。
