先回忆上一课（30 秒）

DAPO 为了稳定长链 RL，把损失从样本级改为token 级——哪句能复述「为什么长垃圾答案与短正确答案等权」？
答：样本级损失下每条序列权重 $1/B$ 与长度无关；token 级按总 token 数归一化，序列影响力 ∝ 长度。

前四课的验证器都是「判词」（看答案、打分数）。这一课的关键跃迁：让模型执行动作，用真实环境结果做反馈——验证从「判断」升级为「行为」。

1. 工具调用：从生成器到智能体

LLM 只会生成文本；带工具的智能体（agent）可以：调用代码解释器、搜索引擎、外部 API、模拟器——执行动作、读取结果、多步迭代。课程定义：智能体是 LLM 的泛化——有目标，能与环境交互，收集反馈并据此纠正自己的步骤。（wiki 页）

工具的价值：它把「生成-验证差距」的验证环节变成动态可得的——不是事后判断答案对不对，而是让程序真的跑起来看结果。符号技术（如形式化工具）也属于工具使用，且是合成数据的重要来源。

2. 执行反馈：最强验证器

在可验证领域，验证机制有一个共同特征：比生成任务本身更简单。（wiki 页）

领域验证器
数学形式化证明（Lean）——机械严谨，逐步校验
编程单元测试——写测试比写程序简单
语言转换输入/输出等价性（AI-as-a-Compiler：PyTorch→CUDA，KernelBench 上覆盖率随采样线性增长）

代码反馈是执行反馈的代表。它有两种用法（注意区分）：

  1. 筛选用：跑测试 → 保留通过候选（第 3 课 AlphaCode 流程）
  2. 学习信号用：执行结果作为奖励喂 RL——RLEF（Reinforcement Learning from Execution Feedback）把「运行代码/跑测试」从判别器升级为引导信号，让模型学会生成「真正能运行、测试通过」的代码（wiki 页）

3. 智能体搜索：搜索空间从「代码」到「轨迹」

课程把搜索分为两类（wiki 页）：

  • 代码模型搜索：大量采样 + 筛选（AlphaCode / AlphaCode 2）——面向代码生成
  • 深度研究式（agent search）：在动作/轨迹空间搜索——面向长时程多步任务（对应作业三）

两者的共同点：模型已经把解蕴含在搜索空间里，关键是如何策展出答案。LATS 是智能体搜索的算法实例。

4. LATS：把 MCTS 引入 LLM 推理路径

LATS（arXiv:2310.04406）将蒙特卡洛树搜索（MCTS）引入 LLM 多步推理，把推理、行动、规划统一在同一个测试时搜索框架中（wiki 页）：

  1. 选择：UCT 平衡探索/利用，选扩展节点
  2. 扩展：采样多个候选行动，并行执行，观测追加上下文
  3. 评估：$\text{分数} = s_{LM} + \lambda\, s_{SC}$——LLM-as-Judge 打分 + 自洽性频率分数（行动越常被采样，分数越高）
  4. 模拟：从最高分状态贪心推进至终点/预算
  5. 反向传播：结果回传，更新路径分数
  6. 反思：对成败轨迹生成解释，回喂后续搜索

效果：HotPotQA / WebShop 上无需微调即接近人类专家水平。⚠️ 限制：隐含假设行动可逆（交易/支付等不可逆场景慎用）；每次扩展/回传都烧大量测试时计算，论文未做成本-收益系统分析。

💡 追问：共享资源的互斥环境怎么办？树搜索从父状态分岔，靠的是「执行 $a_1$ → 回到父状态 → 再执行 $a_2$」——所以真正的地基假设是环境可回放（可重置 / 无副作用），比「可逆」更强。模拟器、检索、沙箱都满足；真实物理资源（如一台设备一次只能被一个操作占用）不满足，LATS 原版未处理。三问判别：①可重置？②可逆？③冲突可观察？「否」越多，越需要适配：建模进状态 / 分层执行 / 换世界模型 → 详见速查卡 §6.1。

5. 闭环对接：工具是验证器，也是学习信号

「生成 → 验证（执行反馈） → 学习（RLEF/RL） → 搜索（LATS）」——三步共用同一把反馈，这正是第 2 讲「通过搜索实现自我改进」在工具层的落地。

值得记住的脉络：数学/编程为什么是自进化最先成熟的领域？因为执行反馈自动、可靠、低成本——验证器比生成简单，闭环才跑得动。

6. 练习：五道题，凭记忆作答

  1. Q1. 工具调用让智能体获得的核心能力是？

    工具调用让模型执行动作、读取环境结果，形成多步迭代——智能体与纯生成模型的分界。

  2. Q2. 执行反馈「最强」的验证器特征是？

    可验证领域的共同点：验证机制比生成简单——才能大规模自动化筛选，否则只是把难题换个地方。

  3. Q3. RLEF 把执行反馈用作？

    RLEF = Reinforcement Learning from Execution Feedback：跑代码/跑测试的结果作为 reward，把验证从判别器升级为训练信号。

  4. Q4. 智能体搜索（agent search）的搜索空间是？

    区别于代码模型搜索（大量采样候选代码），智能体搜索面向深度研究式长任务，在动作/轨迹空间搜索（LATS 代表）。

  5. Q5. LATS 评估阶段合成状态分数的两来源是？

    评估 = LLM-as-Judge 打分 + 自洽性分数（行动被采样越多，分数越高）——状态价值由「看」和「频」共同决定。
